# Vinay G P — Cybersecurity Portfolio

A static, responsive personal cybersecurity project hub built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — portfolio sections and project cards
- `style.css` — styling, responsive layouts, and visual elements
- `script.js` — project detail dialogs, filters, and mobile navigation

## Preview locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a **public** repository on GitHub (for example `cybersecurity-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the deployment to finish and open the URL shown on the Pages settings screen.
